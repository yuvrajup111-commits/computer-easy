What is Microsoft Excel?

Microsoft Excel is a spreadsheet program used to organize, calculate, and analyze information.

Understanding Cells

An Excel worksheet is made of rows and columns. The boxes where rows and columns meet are called cells.

Entering Data

You can enter text, numbers, dates, and other information into cells.

Basic Formulas

Excel can perform calculations using formulas. For example, you can add numbers using a formula such as =A1+B1.

How to Open Microsoft Excel

Click the Start button and type Microsoft Excel in the search box. Select Microsoft Excel from the search results to open it. You can also use a desktop shortcut if you have one.

How to Create a New Spreadsheet

Open Microsoft Excel and select Blank Workbook. A new spreadsheet will open with rows and columns. You can start entering your information into the cells.

How to Enter Data

Click a cell and type your information. Press Enter to move to the cell below. You can enter text, numbers, dates, and other information into an Excel worksheet.

How to Format Cells

Select the cells you want to format. Use the Home tab to change the font, font size, text alignment, borders, or number format. Formatting can make your spreadsheet easier to read.

How to Use a Basic Formula

Excel formulas begin with an equal sign (=). For example, type =A1+B1 into a cell to add the values in cells A1 and B1. Press Enter to calculate the result.

How to Add Numbers with SUM

The SUM function adds numbers together. For example, type =SUM(A1:A5) into a cell to add all the values from A1 through A5. Press Enter to see the total.

How to Calculate an Average

The AVERAGE function calculates the average of a group of numbers. For example, type =AVERAGE(A1:A5) into a cell to calculate the average of the values from A1 through A5. Press Enter to see the result.

How to Sort Data

Select the data you want to organize. Open the Data tab and choose Sort. You can sort information from A to Z, Z to A, smallest to largest, or largest to smallest.

How to Filter Data

Select your data and open the Data tab. Choose Filter to add filter buttons to your column headings. You can then choose which information you want to display.

How to Insert a Chart

Select the data you want to display. Open the Insert tab and choose a chart type, such as Column, Bar, or Pie. Excel will create a chart based on your selected data.

How to Create a Simple Table

Select the range of cells containing your data. Open the Insert tab and choose Table. Make sure the correct data range is selected, then click OK to create the table.

How to Freeze Rows

If your spreadsheet has many rows, you can keep important headings visible while scrolling. Open the View tab, select Freeze Panes, and choose Freeze Top Row.

How to Merge Cells

Select the cells you want to combine. Open the Home tab and choose Merge & Center. The selected cells will become one larger cell. This is useful for creating headings in a spreadsheet.

How to Copy a Formula

Enter a formula in a cell and move your mouse to the small square at the bottom-right corner of the cell. Drag it down or across to copy the formula to other cells. Excel automatically adjusts the cell references.

How to Use AutoFill

Enter a value or pattern in a cell, then drag the small square at the bottom-right corner of the cell. Excel can automatically continue patterns such as numbers, dates, or formulas.

How to Rename a Worksheet

At the bottom of Excel, right-click the worksheet tab. Choose Rename, type the new name, and press Enter. A clear worksheet name can make your spreadsheet easier to organize.

How to Save an Excel Workbook

Click File and choose Save As. Select the folder where you want to save the workbook, enter a file name, and click Save. You can also press Ctrl + S to quickly save your work.
