What is Windows?

Windows is an operating system made by Microsoft. It allows you to use programs, manage files, browse the internet, and perform many other tasks on your computer.

Using the Desktop

The desktop is the main screen you see after signing in to Windows. You can open programs, files, and folders from the desktop.

Files and Folders

Files store your information, while folders help you organize your files.

Start Menu

The Start menu lets you find applications, settings, and other features on your Windows computer.

How to Create a File

You can create a new file by opening a program such as Notepad, entering your information, and choosing Save. Select a folder, enter a filename, and save the file.

How to Create a Folder

To create a folder, open File Explorer, go to the location where you want the folder, right-click an empty area, choose New, and then select Folder. Enter a name and press Enter.

How to Rename a File

To rename a file, right-click the file and choose Rename. Type the new name and press Enter.

How to Copy and Paste a File

To copy a file, right-click it and choose Copy. Open the folder where you want the copy, right-click an empty area, and choose Paste. You can also use Ctrl+C to copy and Ctrl+V to paste.

How to Delete a File

To delete a file, right-click the file and choose Delete. The file will usually move to the Recycle Bin. You can also select the file and press the Delete key on your keyboard.

How to Restore a Deleted File

Open the Recycle Bin to find deleted files. Right-click the file you want to restore and choose Restore. The file will return to its original location.

How to Select Multiple Files

To select multiple files, hold the Ctrl key and click each file you want. You can then copy, move, or delete the selected files together. To select a group of files, click the first file, hold the Shift key, and click the last file.

How to Move a File

Select the file you want to move and press Ctrl+X. Open the folder where you want to move the file, then press Ctrl+V. You can also right-click the file and use Cut and Paste.

How to Create a Shortcut

To create a shortcut, right-click a file or program and choose Show more options, then select Send to and choose Desktop (create shortcut). A shortcut will appear on your desktop for quick access.

How to Open Task Manager

Task Manager lets you see which programs are running on your computer. Press Ctrl + Shift + Esc on your keyboard to open Task Manager. You can also right-click the Start button and choose Task Manager.

Windows Keyboard Shortcuts

Ctrl + C — Copy

Ctrl + V — Paste

Ctrl + X — Cut

Ctrl + Z — Undo

Ctrl + S — Save

Ctrl + A — Select all

Alt + Tab — Switch between open apps

How to Search for a File or App

Click the Search button on the Windows taskbar and type the name of the file, folder, or app you want to find. Windows will show matching results that you can open.

How to Take a Screenshot

Press Windows + Shift + S to open the screenshot tool. Select the area of the screen you want to capture. The screenshot can then be copied or saved.

How to Lock Your Computer

Press Windows + L on your keyboard to quickly lock your computer. You can also open the Start menu, select your account icon, and choose Lock.

How to Shut Down Your Computer

Click the Start button, select the Power option, and choose Shut down. Windows will close your programs and turn off the computer.
