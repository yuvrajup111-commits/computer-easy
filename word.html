What is Microsoft Word?

Microsoft Word is a word-processing program used to create, edit, format, and save documents.

Creating a Document

You can create a new document and start typing text. You can also save the document so you can work on it later.

Formatting Text

Word lets you change the font, size, alignment, and other formatting options to make your document easier to read.

Saving a Document

Use the Save option to store your document on your computer. You can choose a filename and location for the document.

How to Open Microsoft Word

Click the Start button and type Microsoft Word in the search box. Select Microsoft Word from the results to open it. You can also open Word using a shortcut on your desktop if you have one.

How to Create a New Document

Open Microsoft Word and select Blank Document. A new blank page will appear where you can start typing. You can then add and format your text.

How to Type and Edit Text

Click anywhere on the blank page and start typing. To remove text, use the Backspace or Delete key. You can select text with your mouse and then copy, cut, or replace it.

How to Save a Document

Click File and then choose Save As. Select the folder where you want to save the document, enter a file name, and click Save. You can also press Ctrl + S to quickly save your work.

How to Format Text

Select the text you want to change. Use the formatting tools to make text bold, italic, or underlined. You can also change the font, font size, and text alignment.

How to Change Text Alignment

Select the text you want to align. Use the alignment buttons to choose Left, Center, Right, or Justify. Alignment can help make your document easier to read.

How to Insert an Image

Open the Insert tab and choose Pictures. Select an image from your computer and click Insert. You can then move or resize the image in your document.

How to Make a Bulleted List

Place your cursor where you want the list. Open the Home tab and select the Bullets option. Type each item and press Enter to create the next bullet. Press Enter twice to finish the list.

How to Add a Table

Open the Insert tab and choose Table. Select the number of rows and columns you need. Word will insert the table into your document, and you can enter information into each cell.

How to Print a Document

Open the File menu and select Print. Choose your printer and select the number of copies you want. Then click Print to print your document. You can also press Ctrl + P to open the Print window quickly.

How to Undo and Redo Changes

If you make a mistake, press Ctrl + Z to undo your last change. To redo a change, press Ctrl + Y. These shortcuts are useful when editing a document.

How to Find and Replace Text

Press Ctrl + F to search for specific text in your document. To replace text, open the Replace option, enter the text you want to find and the new text you want to use, then choose Replace.

How to Change Page Orientation

Open the Layout tab and select Orientation. Choose Portrait for a vertical page or Landscape for a horizontal page. This is useful when you need more horizontal space in your document.

How to Add Page Numbers

Open the Insert tab and select Page Number. Choose where you want the page number to appear, such as the top or bottom of the page. Word will automatically number the pages.

How to Check Spelling and Grammar

Word can help find spelling and grammar mistakes in your document. Open the Review tab and select Editor or Spelling & Grammar. Review the suggestions and make corrections when needed.
